# Veil Angular Example

This is an example Angular app using the Veil SDK!

## Getting Started

1. First, build the SDK:
   ```bash
   cd ../../sdk
   npm install
   npm run build
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Update `YOUR_FACTORY_ADDRESS_HERE` in `src/main.ts` with your actual factory address

4. Run the app:
   ```bash
   npm start
   ```
